# DimSleuth · 物理公式量纲排错

不是只给一个对错标签，而是把每一步运算的输入量纲、规则和输出串起来，定位到出错的子表达式。

[English](README.md) · [完整语义](docs/semantics.md)

## 一个例子

输入 `x = v*t + a*t`，为符号配置：

- x：m
- v：m/s
- a：m/s^2
- t：s

`v*t` 得到长度，而 `a*t` 得到速度，两者不能相加。点击错误步骤即可看到原公式高亮、输入量纲与运算规则。把最后一项改成 `a*t^2` 后，量纲一致。

**量纲一致不代表物理正确。** 这个例子还可能缺少 1/2 系数；工具不会判断系数、符号、物理前提或数值是否正确。

## 本地运行

安装 Node.js 22.18+ 或 24+，然后运行：

```sh
npm ci
npm run dev
```

在浏览器打开命令打印的网址。无需 API key、账号或后端。网页包含中英文切换、六个物理示例、可点击追踪、七个 SI 基本量纲对比、JSON 项目导入/导出、独立 HTML 报告导出。

```sh
npm test
npm run build
npm run preview
```

构建的 `dist/` 可用任意静态 HTTP 服务器托管，也可在普通本地浏览器直接打开 `dist/standalone.html` 单文件离线版。没有 service worker，不承诺托管页面关闭后可离线重开。

## 语法与边界

- 乘法必须显式书写：`v*t`，不能写 `v t`
- 支持 `+ - * / ^ ( )`，可含一个等号
- 支持 `sqrt sin cos tan exp log`；除 sqrt 外，参数必须无量纲
- 指数必须为纯数值常量算式，例如 `x^(1/2)`；不支持符号指数
- 幂从右向左结合，优先于一元负号：`-x^2` 等于 `-(x^2)`
- 名称区分大小写，以英文字母开头，可含数字和下划线。pi 和 e 是常数
- 基本单位 m、kg、s、A、K、mol、cd；支持常见 SI 导出单位和前缀
- C 表示库仑。摄氏/华氏温度和带偏移温标的运算不支持
- 只检查量纲，不做数值换算，不是方程求解器，也不是完整符号代数系统

详细错误和运算规则当前使用英文，界面和帮助已提供中文。

## 隐私和安全

公式在浏览器里计算，不上传。没有远程字体或分析跟踪。草稿保存需要主动勾选，且只写入当前浏览器的本地存储；语言偏好也保存在本地。项目导入有版本、类型、长度和危险键名校验。HTML 报告对用户内容进行转义，不含脚本。

源代码采用 MIT 许可证。项目借鉴了成熟的量纲分析思路，差异重点是可解释、可追踪的调试体验，而不是宣称发明量纲检查。
